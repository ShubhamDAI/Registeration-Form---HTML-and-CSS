## About the Project

This project demonstrates a **Student Registration Form** developed using HTML and CSS. It provides a simple and user-friendly registration interface where users can enter their full name, email address, and password.

The form includes Submit and Reset buttons to manage user input. It also features a navigation bar, a background image, and a side image to make the registration page visually attractive.

## Tools Used

- HTML
- CSS
- HTML Forms
- Input Elements
- CSS Flexbox

## Features

- Navigation bar with Home, About Us, Contact, and Our Services links.
- Registration form with Full Name, Email, and Password fields.
- Email validation using the HTML `pattern` attribute.
- Required fields to ensure users enter the necessary information.
- Submit button to submit the registration form.
- Reset button to clear the entered information.
- Background image with the `background-size: cover` property.
- Side image displayed alongside the registration form.
- Transparent form container with rounded corners and a box shadow.
- Hover effects on navigation links and buttons.
